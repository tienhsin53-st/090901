# 090901
# 仙台與山形雪景行程 (Sendai & Yamagata Winter Itinerary)

## 行程概覽
* **地點**：日本東北（仙台、山形、藏王、松島）
* **亮點**：輪王寺雪景庭園、山形藏王樹冰、山寺雪景、松島海岸

---

## 每日詳細行程

### Day 1：抵達仙台與歷史庭園漫遊
* **上午/中午**：抵達仙台，前往飯店辦理 Check-in / 寄放行李。
* **下午**：
  * **仙台輪王寺**：參觀經典日式庭園，欣賞冬雪覆蓋下的枯山水與五重塔景致。
* **傍晚/晚上**：
  * 返回仙台車站周邊逛街，享用知名名產**仙台牛舌定食**。

---

### Day 2：松島海岸與仙台市區巡禮
* **上午**：前往日本三景之一的**松島**，搭乘遊覽船欣賞灣內雪景與島嶼風光，參觀瑞嚴寺與五堂堂。
* **下午**：返回仙台市區，走訪**瑞鳳殿**或**仙台城跡（青葉城）**，俯瞰仙台雪白市景。
* **晚上**：市區自由購物，享用仙台在地美食（如蒲鉾、毛豆餅等）。

---

### Day 3：山形雪景與藏王樹冰
* **上午**：搭乘 JR 仙山線前往山形，轉乘巴士前往**藏王溫泉**。
* **下午**：搭乘藏王索道纜車（Zao Ropeway）登上山頂，欣賞壯觀的**藏王樹冰（Ice Monsters）**。
* **晚上**：入住藏王溫泉飯店，體驗雪見溫泉與山形牛料理。

---

### Day 4：山寺雪景與返程
* **上午**：前往**寶珠山立石寺（山寺）**，沿著石階登高，居高臨下俯瞰宛如水墨畫般的雪白山谷景色。
* **下午**：返回仙台車站採買伴手禮，前往機場/車站搭車返程。

---

## 備註與注意事項
* 冬季東北雪地步道較滑，建議穿著防水且防滑的雪靴，並準備懷爐與防風保暖衣物。
* 藏王樹冰纜車與山寺階梯視天候狀況可能調整，出發前請留意運行與開放資訊。
